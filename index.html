Политика конфиденциальности приложения «ESB:Задачи»

Дата вступления в силу: 19.10.2026.
Разработчик приложения: alexeybyimistrov («Разработчик»).
Контакт для вопросов о конфиденциальности: alexeybyimistrov@gmail.com.

1. О чём эта политика

«ESB:Задачи» — мобильное приложение для сотрудников организаций: получение и выполнение полевых задач, проверок по чек-листам, фотоотчётов. Приложение является клиентом и не работает без сервера организации, в которой работает пользователь. Адрес сервера и учётную запись выдаёт администратор организации.

Персональные данные пользователей обрабатываются прежде всего сервером их собственной организации. Разработчик приложения не имеет доступа к этим данным, не хранит их и не обращается к ним.

2. Какие данные и зачем

ДанныеЗачемКуда попадают
Имя пользователя (логин) и пароль Вход в систему. Пароль используется только для получения токена; на устройстве хранится не сам пароль, а его медленный хэш для офлайн-входа Сервер организации; хэш — в защищённом хранилище устройства
Местоположение (точное) Подтверждение, что задача выполняется на объекте; выбор ближайшего объекта; фиксация координат при старте и завершении работы Сервер организации
Фото и видео Фотофиксация выполнения задач и пунктов чек-листов Сервер организации
Комментарии и ответы на пункты бланков Содержание выполняемых задач Сервер организации
Идентификатор устройства и токен push-уведомлений (FCM) Доставка push-уведомлений о новых задачах и сроках; версия сборки — для поддержки Сервер организации; токен — сервис Google Firebase Cloud Messaging
Локальный кэш (список задач, оформление, адрес сервера) Работа приложения без сети (офлайн-режим) Только устройство; удаляется выходом из учётной записи или удалением приложения

3. Кому передаются данные

  • Сервер организации, в которой работает пользователь, — все данные из таблицы выше.
  • Google (Firebase Cloud Messaging) — исключительно технический токен для доставки push-уведомлений; содержание уведомлений формирует сервер организации.

Приложение не содержит рекламу, не подключает аналитические и трекинговые SDK и не продаёт и не передаёт данные каким-либо третьим лицам.

4. Хранение и сроки

Данные на сервере организации хранятся в соответствии с правилами и сроками этой организации. Локальные данные на устройстве хранятся до выхода из учётной записи («Выйти и удалить данные» в приложении) или удаления приложения.

5. Ваши права

Доступ к своим данным, их уточнение и удаление выполняются через администратора вашей организации: учётная запись сотрудника создаётся и удаляется на стороне организации. Вопросы, которые организация решить не может, — на alexeybyimistrov@gmail.com.

6. Безопасность

Токен сеанса, учётные данные и хэш пароля хранятся в системном защищённом хранилище устройства (Android Keystore). Защита данных при передаче определяется настройкой сервера организации; при подключении по HTTPS трафик шифруется.

7. Возрастные ограничения

Приложение предназначено для использования совершеннолетними сотрудниками организаций и не адресовано детям.
